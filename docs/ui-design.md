## F16 账号管理方向与边界（2026-10-15）

沿用用户批准的 AntD 消息工作台方向：纸白、深蓝操作、低饱和状态、细分隔与 4px 节奏。账号域是文件组、已核验身份、连接状态、账号分组、群角色与检测记录；不增装饰仪表盘。标题改为“账号管理”，上传为主操作，实际计数与搜索/筛选直接领先表格。

根因是 MainLayout.content 的 max-width:1600px。仅 accounts 路由使用 contentAccounts modifier：满可用宽度、48px header 后的剩余视口高度；账号 section 纵向 flex，表格按剩余空间内部滚动，分页始终可见。窄桌面允许表格横向滚动，固定操作列；完整手机号可见/复制，账号 ID 可换行。每页 20/50/100，筛选回到第一页，统计来自全体实际返回账号。

详情采用 1080px AntD Modal，基础信息/所在群/操作日志三标签，body 限 72dvh；打开与切换标签仅读持久数据。离线动作明确“连接并检测”，在线“检测”，终态不出现连接/检测。群同步仅 online；离线解释先连接；角色区分群主、管理员、成员、未知。手机号区分待核验与 Telegram 已核验；只有 Telegram 读取成功后，空用户名才显示“未设置”。viewer 只保留查看、复制、查询；写按钮与批选隐藏。

上传 Modal 保留原生多选文件输入，AntD Form/Select/预览表格承接分组和配对结果；缺失或歧义必须先修正，服务端逐账号失败保留可读中文与安全 code。分组删除明确“账号移至未分组，不删除账号”；批移失败保留选择/目标和弹窗。加载、空、失败、重试均就近呈现。

1366/1920/2560×900 桌面以 61 条合成 HTTP 展示夹具验证全宽、视口内分页、内部滚动与切页；截图 .local/inspection-20261015/iris/accounts-{1366,1920,2560}.png，人工看图确认 1366 和 2560 无页面横溢或空白右区。该夹具不证明实际账号导入或 Telegram 连通性；真实栈证据单列于 TDD 记录。

## R25 主控：全宽布局与紧凑剧本编辑

用户明确要求主控独立实施，本轮使用 interface-design，继续采用现有 AntD 原语与消息工作台方向。领域为账号身份、群角色、剧本步骤、发送延迟、预览变量和 AI 草稿；颜色沿用纸白、冷灰、深蓝、低饱和绿与暗红。签名是同一剧本在左侧步骤轨迹和右侧角色对话中的同步呈现。取消局部全宽特例，公共内容区统一铺满；取消派生的深灰选中态，表格/选项以浅蓝表达选择；替换全部展开的大文本表单为摘要折叠与独立预览。

组件检查点：页面主区优先业务表格，保留24px桌面边距；选中背景#edf4fa，悬停#e2edf6，正文颜色不降低；编辑器以步骤为主、预览为辅，约1.35:1，两个区域独立滚动，保存常驻底部。标题16px/600、内容13px、摘要/元数据12px，4px节奏，紧凑行至少48px；继续使用Segoe UI/Microsoft YaHei与既有语义变量，无装饰渐变。窄屏导航收缩，表格局部横滚，编辑/预览上下排列。

AI结果先作为待采用草稿显示，保留用户正在编辑的JSON，采用或放弃后才允许保存；预览变量不写入剧本。剧本库展开预览与编辑器复用SequencePreview。模型密钥仅在provider服务，浏览器只提交场景和步骤数；生成不绑定账号、不启动序列。设计根据用户明确的问题直接实施，没有新增方向确认步骤。

本地真实服务页面在1366/1920/2560宽度中均保留24px右边距，未发生页面横溢。实际账号行最终选中颜色rgb(237,244,250)。20步未保存编辑草稿在1440×900中保持保存按钮可见，折叠后不丢数据，变量即时预览；浏览器无运行错误。截图位于忽略目录.local/inspection-20261015/ui-r25，不将编辑示例作为真实群执行证据。

## R27 群管理界面与营销状态

延续interface-design已批准的纸白/深灰/低饱和蓝，群是工作区，Agent是持续待命身份，run只是每次处理记录。列表固定操作列复用结束营销按钮；主区四tab使用AntD 6实际body-holder/body/content结构，取消旧grid将Tabs误当三个子元素的布局。聊天独立滚动：底部跟随、读历史不抢滚动、加载早期消息保留位置、按钮回最新。右侧操作固定在前，成员与处理记录各自限高滚动，避免记录将控制项挤出页面。

剧本左配置右角色对话，变量由占位符生成有标签的输入，逐步JSON折叠。先本地填写提示，再后台预检，最后明确确认发送；共享SequencePreview及变量识别，删除旧原始vars表单和已替代Agent步骤列表样式。已读外部提示为浅蓝紧凑条，查看后消失，新消息才再次提醒。群操作日志逐条表格，Agent工具轨迹表格显示真实回复并折叠原始详情，历史scripted记录明确标注。

800/1366/1920/2560宽度实页无横向溢出，tab与面板边缘相接无重叠；预览角色/变量/账号及最终后台检查通过。实际聊天默认滚到最新、可上滚并回到底部；截图在ignored .local/inspection-20261015/ui-r27。未执行现场发送、暂停或退群；实际操作由用户验收。

R28：群详情通过父级固定视口与内部flex/grid分配剩余高度，删除250px猜测偏移及560px最小高度。提示出现/消失都重新分配空间；聊天和右栏保持局部滚动，页面外层不滚动。仅应用于群详情路由。
