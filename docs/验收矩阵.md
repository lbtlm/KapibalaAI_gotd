## 真实 Telegram 已验证的范围

- 三份隔离 Session 副本认证成功，并各自加入指定测试群一次；源文件保持原样。
- 两个服务账号通过真实 gateway HTTP 连接。第三个账号保留为外部触发者，尚未连接到业务后端。
- G2 精确发送一条标记消息、一次 POST、零重发。202 受理、唯一发送回执、两个在线服务账号下唯一 own 消息、按 clientMsgId 查询、原 eventId 重连补拉、独占游标无重复，八项检查通过。
- 未把 fake 故障测试当作真实 Telegram 证据。真实建群、提升、成员移除、退群、进程故障恢复和完整 Agent 链路仍需分别记录，不能由正常单条收发推断。
